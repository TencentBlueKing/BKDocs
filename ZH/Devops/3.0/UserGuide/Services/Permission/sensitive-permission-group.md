# 敏感权限用户组管理须知

本文供项目管理员与资源拥有者在授权、审批和交接时遵守。操作路径见同目录其他文档。此处说明高风险操作的后果与约束。

权限分为两类，交接时须同时处理。

- **用户组权限**：决定成员在 BK-CI 内可执行的操作及资源范围。
- **个人授权**：决定无登录态时系统以何人身份拉取代码、触发流水线。包括流水线权限代持人、代码库连接授权。详见 [授权管理](authorize.md)。

仅移出用户组而个人授权仍挂在原成员名下时，流水线会继续使用其身份执行，或因身份失效而执行失败。成员已无操作权限、但曾做过个人授权的，移出项目前须由新负责人重新授权。

## 高风险操作

下列操作的影响面覆盖代码、凭据、构建环境、节点或项目内全部资源。执行前须确认必要性、对象范围和有效期。无法确认的，不予授权。

| 操作 | 主要风险 | 约束 |
| ---- | ---- | ---- |
| 向管理员组添加成员 | 管理员拥有项目下全部资源的操作与管理权限，包括使用已关联的代码库连接、凭据和证书、审批项目级权限申请、移出成员、批量重置代持人。 | 有效期按职责给予。**谨慎赋权。** |
| 向用户组添加组织 | 组织内现有成员立即获得权限；此后加入该组织的成员自动获得，离开则自动失去。 | 能使用凭据（特别是项目下所有凭据）、使用代码库连接（特别是项目下所有代码库连接）、使用所有构建环境和节点、删除资源、编辑任意流水线、执行生产流水线的用户组，不建议添加组织。 |
| 授予项目范围内的编辑任意流水线、使用所有构建环境和节点、删除、执行、使用代码库连接、凭据或证书，或分享制品 | 用户组将操作勾选到**整个项目/任意资源**后，组内成员对全部同类资源生效。编辑任意流水线的成员可以修改项目内全部流水线的编排与设置。使用所有构建环境和节点的成员可以在流水线中选用项目内全部构建环境和节点。 | 能收窄到指定流水线、流水线组、构建环境或节点的，不授予整个项目。只需少量流水线权限的，加入对应流水线的权限组；只需使用部分构建环境或节点的，加入对应构建环境或节点的权限组。<br>**非必要不给**用户组开启项目级或任意资源实例范围的权限。 |
| 使用代码库连接、凭据或证书 | 拥有「使用」权限的用户可在流水线中选用对应资源，不能查看内容。 | 生产口令的拥有者限于必要人员。流水线只需选用时，只授予使用者。 |
| 指定或重置流水线权限代持人 | 代码库触发、定时触发、远程触发、OpenAPI 触发，以及父流水线调用子流水线时，以代持人身份做权限校验。子流水线使用子流水线自身的代持人。构建中的文件操作记在代持人名下，构建记录可见该身份。 | 代持人须持续拥有该流水线的执行权限。流水线调用子流水线的，代持人还须拥有那些子流水线的执行权限。不得指定管理员或权限超出该流水线需要的账号。 |
| 进行代码库连接授权 | 流水线拉取代码时使用授权人在代码平台上的身份。授权人在代码平台可读取的仓库，流水线运行时可读取。 | 授权人只保留本项目所需仓库的读取权限。 |
| 审批组织加入、长期限或项目级权限 | 组织申请通过后，覆盖该组织现有成员及此后进出组织的人员。长期限和项目级范围按所批用户组的实际权限生效。 | 核对申请对象、用户组实际操作、资源范围和有效期。组织、长期限或项目级范围无法确认必要时，不予通过。 |
| 移交唯一管理员或唯一拥有者 | 接收人将承担该组全部权限。 | 交给实际负责该项目或资源的人。 |
| 最大可授权人员范围保持为全部成员 | 项目未收窄该范围时，范围内的全部用户均可被授权，也均可作为交接人。 | 项目成员稳定后，将范围限定为实际使用该项目的组织与人员。 |

## 权限叠加

同一资源上的权限来自三处，同时生效：

- 项目级用户组
- 资源自身的用户组
- 已开启权限管理的流水线组

从一处移出后，其余来源仍在的，权限仍然有效。回收前须核对该成员的全部来源。

编辑者、执行者、查看者可以添加项目用户组。添加后，该用户组的成员变化直接作用于这条流水线。要收回其中一人，到项目用户组中调整。

自定义用户组选中一项操作时，系统会同时带上进入项目、查看列表所必需的操作。提交前核对最终操作与资源范围，确认编辑任意流水线、使用所有构建环境和节点、删除、分享、执行未被一并放开。

## 审批、续期与移交

续期前确认该成员仍承担对应职责。

离职或职责变更前完成交接。

代持人默认为流水线创建人。保存流水线不会将代持人改为最后修改人。创建人离职或职责变更后，须单独重置代持人。

## 定期核查

项目管理员每季度核查下列事项。

- 管理员组是否仍有已离职或不再负责该项目的成员。
- 自定义用户组是否将编辑任意流水线、使用所有构建环境和节点、删除、执行、使用凭据、证书或代码库连接开放至整个项目。
- 生产流水线、凭据、代码库连接的拥有者是否仍负责对应资源。
- 代持人与代码库连接授权人是否仍为项目内的有效成员，定时触发与自动触发是否正常。
- 最大可授权人员范围是否仍限于实际使用该项目的人员。
