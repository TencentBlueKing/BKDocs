# 4. 创建目录和仪表盘

本教程在 **验收专用空间_勿删** 中组织国家画像看板。已有 **船新的数据面板[Light_PC]** 时可直接进入编辑，新建看板时按以下步骤配置。

## 创建目录

![新建目录表单](../Media/Quick-Starts/Quickstart-04-directory.png)

展开仪表盘目录导航，在“全部”旁单击“新增 → 目录”。填写目录名称，例如“文档示例_国家画像”，选择所属目录后确认。

## 创建仪表盘

![新建仪表盘表单](../Media/Quick-Starts/Quickstart-04-dashboard.png)

单击“新增 → 仪表盘”，填写名称并选择所属目录。名称可使用“文档示例_国家画像看板”，与已有业务资源区分。

创建后进入编辑画布，添加图表。浏览已有详情时，本教程固定使用“船新的数据面板[Light_PC]”，后续选择已验证的国家画像数据集。

下一步：[5. 在仪表盘内配置图表](5.Chart-configuration.md)。
