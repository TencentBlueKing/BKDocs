# 蓝鲸节点管理（BlueKing Node Manager）

蓝鲸节点管理（bk-nodemgr）是蓝鲸体系中的主机节点管控服务，为管控节点上的 GSE Agent 提供安装、升级、重载配置、重启、卸载等一系列生命周期控制能力，并支持跨网络区域的 Proxy 桥接管控、配置策略、插件管理与包管理。

- 源码仓库：[TencentBlueKing/bk-nodemgr](https://github.com/TencentBlueKing/bk-nodemgr)
- 开源协议：MIT
