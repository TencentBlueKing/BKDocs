# 特点及优势

## 云原生微服务架构

服务层由 Application、Backend、File 三个基本模块构成，均为无状态服务，可横向扩展；支持部署在蓝鲸 PaaS 平台，或通过 Helm / docker-compose 直接部署，支持滚动升级与优雅停机，保障升级过程业务无损。

## 灵活的跨网络管控

通过「管控区域 + 管控单元 + 接入点」三层拓扑模型灵活描述网络环境：区域描述网络归属，单元描述管理路径（直连 / 经 Proxy），接入点描述单元之间的连接地址。支持对多个管控区域进行多层级 Proxy 桥接管控，以及多接入点管理。

## 多样的安装方式

- **在线自动安装**：Backend 或 Relay 通过 SSH/WMI 登录目标主机触发安装，文件传输与状态回写通道按拓扑自动选择。
- **手动安装**：由 Backend 生成引导命令，管理员在目标主机上手动执行完成安装。
- **离线安装**：针对完全无法访问管控面网络的环境，管理员手动下载离线包执行安装（适用于 Proxy）。

## 声明式插件部署策略

部署策略以声明式方式定义插件在目标节点上的期望状态：期望存在但实际不存在时安装，版本不匹配时升级，不再属于期望集合时卸载。目标范围支持动态拓扑、集群模板、服务模板、实例、动态分组等多种选择方式。

## 灵活的配置策略

支持 Agent 配置策略、Proxy 配置策略与插件配置策略，可按多条件组合自定义节点配置并编排下发，配置变更通过重载（Reconfig）生效，无需重装节点。

## 实时任务日志

安装、升级等任务异步执行，任务历史中可实时查看每个子任务的执行状态与日志，方便定位问题。

## 支持多种操作系统

**Linux 主机**：支持主流的 Linux 操作系统，包括但不限于 CentOS、Ubuntu、SuSE、Debian 等。

**Windows 主机**：支持 Windows Server 系列服务器。

**macOS 主机**：支持 Darwin（macOS）系统。

> 支持的操作系统范围以后端配置中 `gseDeployConfs` 实际配置的条目为准，官方默认提供 linux / windows / darwin 三类。
