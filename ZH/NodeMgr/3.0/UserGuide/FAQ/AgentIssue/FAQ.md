# Agent 常见问题

## 安装 Agent 有哪些前置条件？

- 直连单元：目标主机的 SSH（Linux/macOS）或 WMI（Windows）通道可用；目标主机能访问节点管理 File 服务的 `download` 地址和 Backend 的 `callback` 地址；目标主机能访问单元直连配置中的 GSE 地址。
- 非直连单元：目标主机能访问本单元的 Proxy；单元内 Proxy 具备安装能力且 Relay 插件运行正常。

如果不满足在线安装条件，可以改用**手动安装**：由系统生成引导命令，复制到目标主机上手动执行。

## 安装时提示主机已存在怎么办？

节点管理按「管控区域 + 内网 IP」校验主机唯一性。如果提示主机已存在，说明该组合在蓝鲸中已有记录，安装程序会忽略这批主机。如需重装，请先对已有主机执行卸载或移除。

## 修改了管控单元直连地址或接入点后，节点为什么还是旧配置？

修改直连地址、上游选择或接入点配置后，已有节点不会立即更新配置，需要对对应的 Agent 或 Proxy 执行**重载（Reconfig）**。重载会重启节点服务，请安排合适的操作时间，并在任务历史中确认任务成功。
