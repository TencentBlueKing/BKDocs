# 产品简介

蓝鲸节点管理（bk-nodemgr）是蓝鲸体系中新一代的主机节点管控服务（节点管理 V3），基于 Go 微服务架构重构，为管控节点上的 GSE Agent 提供安装、升级、重载配置、重启、卸载等全生命周期控制能力。

节点管理支持对常见的 Linux、Windows、macOS（Darwin）操作系统主机进行自动化部署，并通过「管控区域 + 管控单元 + 接入点」的拓扑模型提供跨网络管理方案：对于存在网络隔离的区域，只需在该区域内部署 Proxy 节点，即可桥接管控该区域内的主机，帮助企业轻松应对多网络区域的 IaaS 设备管控。

## 核心功能

- **管控区域管理**：灵活划分管控单元，支持对多个管控区域进行多层级的 Proxy 桥接管控，支持多接入点管理。
- **节点管理**：对管控节点的 GSE Agent 提供安装、升级、重载配置、重启、卸载等一系列控制服务。
- **策略管理**：支持灵活的配置策略，提供多条件下的 GSE Agent 自定义配置组合和编排。
- **插件管理**：支持插件的基础操作及部署策略，支持大规模节点的插件生命周期控制。
- **包管理**：支持 GSE Agent / Proxy / Plugin 等包的版本管理与控制。
