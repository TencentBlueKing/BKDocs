# 基本概念

## Host（主机）

主机是节点管理中的主机领域模型，承载 CMDB 主机属性（静态属性，如主机 ID、内网 IP、所属业务拓扑）和节点管理运行态属性（动态属性，如节点角色、状态、版本、登录信息等）。节点管理以 CMDB 主机 ID（`host_id`）作为识别主机的主键。

## Node（节点）

节点是由节点管理管理的对象，围绕 Agent 或 Proxy 的安装、升级、重载、重启、卸载等生命周期操作展开。节点角色（`node_role`）主要包括 Agent 和 Proxy 两种。

## Agent

普通节点角色，承载目标主机上的 GSE Agent 能力。在主机上安装 Agent 后，蓝鲸即可对该主机进行管控，包含文件分发、作业执行、数据上报、基础信息采集等。

## Proxy

跨网络场景下的节点角色，承载所在管控单元内的 Agent 控制、文件通道、数据通道、Relay 服务等能力。在非直连的管控单元中，需要先安装 Proxy 才能管控该单元内的主机。为了负载均衡和容灾，您可以在一个管控单元中安装多个 Proxy。

## Relay

管理非直连单元的节点时，节点管理会在 Proxy 节点上托管一组名为 `bk-nodemgr-relay` 的常驻插件服务，提供对该单元的节点管理能力（安装跳板、HTTP 下载、回调转发等）。Relay 与 Proxy 节点的 Agent 通过 domain socket 通信，依赖 GSE 的上下行信令通道实现跨网络通信。

## 管控区域（Network Area）

管控区域用来区分主机所属的网络范围，对应 CMDB 中的管控区域（也叫云区域），区域 ID 也用于 GSE 识别主机所属的网络。不同网络可能使用相同的内网 IP，管控区域用于区分这些主机，避免仅凭 IP 混淆。ID 为 `0` 的区域是默认管控区域。

## 管控单元（Network Unit）

管控单元是节点管理的代理管控基本单元，用来组织一组采用相同接入方式管理的节点。每个单元属于一个管控区域，决定其中的 Agent 是直接连接 GSE（直连单元），还是经过本单元的 Proxy 连接上游（非直连单元）。**区域描述网络归属，单元描述管理路径。**

## 接入点（Access Point）

接入点是一组带名称的 GSE 接入地址（cluster 信令通道、file 文件通道、data 数据通道），在管控单元中配置，供其他管控单元的 Proxy 连接使用。接入点是地址配置，不是一台 Proxy，也不是额外部署的服务。

## 插件包 / 插件 / 进程

- **插件包（Package）**：静态资源，有明确版本，全局共享。
- **插件（Plugin）**：业务概念，按租户隔离，同一租户下唯一，本身不携带版本。
- **进程（Process）**：插件在主机上的运行实例，有生命周期（创建 → 运行 → 停止/销毁）；每台主机上同一插件只能拥有一个进程实例。

插件是可由 GSE Agent 托管调度的子程序或脚本。您可以通过插件开发框架自定义插件，通过节点管理下发部署到主机上，拓展更多管控功能。

## 部署策略（Deploy Policy）

部署策略以声明式方式定义插件在目标节点上的期望部署状态，由目标范围（scope）和期望状态（spec）组成。被目标范围覆盖的节点，将按照策略定义的规则自动进行插件的部署安装。
