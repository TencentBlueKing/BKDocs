# 开源共建指南

蓝鲸节点管理（bk-nodemgr）已在 GitHub 开源，欢迎通过 Issues 或 Pull Requests 参与社区共建。

- 仓库地址：[https://github.com/TencentBlueKing/bk-nodemgr](https://github.com/TencentBlueKing/bk-nodemgr)
- 开源协议：[MIT](https://github.com/TencentBlueKing/bk-nodemgr/blob/master/LICENSE.txt)

## 基本要求

1. **Issue 规范**：提交 Issue 时请按照仓库的 Issue 模板（bug_report / feature_request / discussion）填写，尽可能提供版本号、复现步骤、日志等信息。
2. **PR 规范**：提交 Pull Request 前请阅读仓库中的 [Contributing Guide](https://github.com/TencentBlueKing/bk-nodemgr/blob/master/.github/CONTRIBUTING.md)，了解分支管理、Issue 与 PR 规范，并按 PR 模板填写变更说明。
3. **行为准则**：参与社区协作时请遵守 [行为准则](https://github.com/TencentBlueKing/bk-nodemgr/blob/master/.github/CODE_OF_CONDUCT.md)。
4. **版本说明**：节点管理 V3 的版本命名遵循 `v{major}.{minor}.{patch}-{phase}.{serial}[-{mark}]` 规则（如 `v3.0.1-beta.1`），Git Tag 与发布包版本保持一致。
