## 术语表

本文统一说明 BKBase 产品文档中常用的概念。具体字段和页面操作以对应功能文档为准。

| 术语 | 说明 |
| --- | --- |
| 业务 | 数据归属的基础范围。数据源和结果数据通常归属于某个业务。 |
| 项目 | 组织数据开发、成员协作和权限管理的工作空间。Dataflow 和自定义函数在项目上下文中进行管理。 |
| 项目管理员 | 负责项目资料和成员维护，并拥有该角色关联的管理权限。人员加入“项目管理员”字段后即获得对应角色权限。 |
| 项目观察员 | 以查看、观察和协作为主的项目角色。人员加入“项目观察员”字段后即获得对应角色权限。 |
| 数据连接 | 可复用的外部系统连接配置，用于保存连接类型、地址和认证等信息。 |
| 数据源 | 一个具体的数据采集项，包含来源类型、采集范围、上报方式、运行状态和通知配置。 |
| 原始数据 | 数据源接入后、尚未完成结构化处理的数据。 |
| 样例数据 | 从数据源最近上报内容中选取的调试输入，用于设计和验证清洗规则。 |
| 清洗任务 | 将原始数据转换为结构化结果数据的持续处理任务。 |
| 清洗算子 | 清洗编辑器中执行解析、提取、转换、过滤或结构处理的节点。可用算子会随当前节点的数据类型变化。 |
| 输出数据配置 | 配置结果表名称、字段来源、字段名称、类型、说明及时间字段的位置。BKBase V4 在此处完成字段映射。 |
| Schema | 数据的字段结构，包括字段名称、类型、说明、维度属性及时间相关配置。 |
| 数据集 | 经清洗或计算并配置存储后，可供查询和下游任务使用的结果数据。 |
| 结果数据表 | 数据集在平台中的表级标识，通常由业务标识和英文表名组成，也常简称为结果表。 |
| Dataflow | 使用可视化节点和连线编排的数据处理任务，也可简称为 Flow。 |
| 数据源节点 | Dataflow 的输入节点，用于选择已有的实时流水表、离线流水表或维表。 |
| 处理节点 | Dataflow 中执行实时计算、离线计算、指标计算、分流、合流或自定义处理的节点。 |
| 存储节点 | 将上游结果数据写入指定存储的节点。 |
| 实时计算 | 持续消费到达的数据并产生结果，适合实时转换、过滤、关联和窗口统计。 |
| 离线计算 | 按计划处理指定范围的数据，适合批量加工和周期产出。 |
| 窗口 | 实时或离线统计的时间处理规则，包括无窗口、滚动窗口、滑动窗口、累加窗口和会话窗口等。 |
| 数据时间 | 用于表达事件发生时间或平台处理时间的字段。实际可用字段以结果数据表 Schema 为准。 |
| BKSQL | BKBase 数据开发和数据探索使用的 SQL 语言能力。具体函数和语法以页面校验结果为准。 |
| PromQL | 面向时序指标数据的查询语言，在符合存储条件时用于指标查询和计算。 |
| UDF | 用户自定义标量函数，对每行输入产生一个输出。 |
| UDAF | 用户自定义聚合函数，将多行输入聚合为一个输出。 |
| UDTF | 用户自定义表函数，可将一行输入展开为多行输出。 |
| 入库任务 | 将清洗或计算结果持续写入目标存储的任务。 |
| 存储资源 | 承载结果数据的存储能力，例如 ES、Doris、HDFS、MySQL 或 VictoriaMetric。 |
| 计算资源 | 承载实时、离线或其他数据计算任务的资源。 |
| 保留周期 | 数据在目标存储中保留的时间范围。到期数据按存储策略处理。 |
| 数据血缘 | 记录数据从哪里产生、经过哪些处理以及被哪些下游使用的关联关系。 |
| 操作权限 | 决定成员可以对项目、数据、任务、函数或资源执行哪些操作。 |
| 操作对象范围 | 在拥有某项操作权限的基础上，进一步限定成员可以操作哪些具体对象。 |
