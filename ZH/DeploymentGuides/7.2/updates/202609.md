
# 20260909

## 监控平台

### bk-monitor-3.9.0-beta.38

这是 **安全更新**，修复了安全问题，请尽快安排更新。
<!-- 版本日志见 GitHub_URL 。-->

登录到 **中控机**，先更新 helm 仓库缓存：
``` bash
helm repo update
```
检查仓库里的版本：
``` bash
helm search repo bk-monitor --version 3.9.0-beta.38
```
预期输出如下所示：
>``` plain
>NAME                 CHART VERSION  APP VERSION  DESCRIPTION
>blueking/bk-monitor  3.9.0-beta.38  略             略
>```

接下来开始升级了。

先进入工作目录：
``` bash
cd $INSTALL_DIR/blueking/  # 进入工作目录
```

修改 `environments/default/version.yaml` 文件，配置 bk-monitor charts version 为 `3.9.0-beta.38`：
``` bash
sed -i 's/bk-monitor:.*/bk-monitor: "3.9.0-beta.38"/' environments/default/version.yaml
grep bk-monitor environments/default/version.yaml  # 检查修改结果
```
预期输出：
>``` yaml
>  bk-monitor: "3.9.0-beta.38"
>```

更新 bk-monitor：
``` bash
helmfile -f 04-bkmonitor.yaml.gotmpl -l name=bk-monitor sync
```

等待命令执行完毕，结尾输出如下即为更新成功：
>``` plain
>UPDATED RELEASES:
>NAME        CHART                VERSION
>bk-monitor  blueking/bk-monitor  3.9.0-beta.38
>```

## 作业平台

### bk-job-0.7.5-beta.3

这是 **安全更新**，修复了安全问题，请尽快安排更新。
<!-- 版本日志见 GitHub_URL 。-->

>**注意**
>
>我们在 bk-job-0.7.4-beta.4 新增了配置加密步骤，如未配置，请参考文档[配置加密](./202605.md#bk-job-0.7.4-beta.4)。<br />
>如未配置并更新至新版本，服务会出现 “Unable to calculate signature using RSA PrivateKey. Could not sign data” 报错日志。

登录到 **中控机**，先更新 helm 仓库缓存：
``` bash
helm repo update
```
检查仓库里的版本：
``` bash
helm search repo bk-job --version 0.7.5-beta.3
```
预期输出如下所示：
>``` plain
>NAME             CHART VERSION  APP VERSION  DESCRIPTION
>blueking/bk-job  0.7.5-beta.3   略           略
>```

接下来开始升级了。

先进入工作目录：
``` bash
cd $INSTALL_DIR/blueking/  # 进入工作目录
```

生成作业平台所需的证书配置

```bash
touch ./environments/default/bkjob-custom-values.yaml.gotmpl
./scripts/generate_jobGateway_tls_cert.sh --san JOB_SERVER --days 18250 -f ./environments/default/bkjob-custom-values.yaml.gotmpl
```

> **注意**
> 
> 如果脚本不存在，可执行命令获取：`{ tmp_dir=$(mktemp -d); bkdl-7.2-stable.sh -ur latest bkhelmfile -i "$tmp_dir" ; cp -a "$tmp_dir"/blueking/scripts/generate_jobGateway_tls_cert.sh $INSTALL_DIR/blueking/scripts; }`

修改 `environments/default/version.yaml` 文件，配置 bk-job charts version 为 `0.7.5-beta.3`：
``` bash
sed -i 's/bk-job:.*/bk-job: "0.7.5-beta.3"/' environments/default/version.yaml
grep bk-job environments/default/version.yaml  # 检查修改结果
```
预期输出：
>``` yaml
>  bk-job: "0.7.5-beta.3"
>```

更新 bk-job：
``` bash
helmfile -f base-blueking.yaml.gotmpl -l name=bk-job sync
```

等待命令执行完毕，结尾输出如下即为更新成功：
>``` plain
>UPDATED RELEASES:
>NAME    CHART            VERSION
>bk-job  blueking/bk-job  0.7.5-beta.3
>```
