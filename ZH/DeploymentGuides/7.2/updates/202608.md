
# 20260824

## 制品库

### bkrepo-配置更新0824

这是 **安全更新**，修复了安全问题，请尽快安排更新。
<!-- 版本日志见 GitHub_URL 。-->

先进入工作目录：
``` bash
cd $INSTALL_DIR/blueking/  # 进入工作目录
```

生成密钥
```bash
secret_key=$(openssl rand -hex 32)
export secret_key
```


修改 values 文件
```bash
touch environments/default/bkrepo-custom-values.yaml.gotmpl

yq -i '.common.config.security.auth.jwt.secretKey = strenv(secret_key)' environments/default/bkrepo-custom-values.yaml.gotmpl
```

部署更新配置
```bash
helmfile -f base-blueking.yaml.gotmpl -l name=bk-repo apply

# 重启服务
kubectl rollout restart deployment -n blueking -l app.kubernetes.io/name=bkrepo
```


检查配置是否已更新
```bash
helm -n blueking get values bk-repo | yq .common.config.security.auth.jwt.secretKey
```

# 20260825

## 监控平台

### bk-monitor-3.9.0-beta.36

这是 **补丁更新**，修复了一些问题。
<!-- 版本日志见 GitHub_URL 。-->

登录到 **中控机**，先更新 helm 仓库缓存：
``` bash
helm repo update
```
检查仓库里的版本：
``` bash
helm search repo bk-monitor --version 3.9.0-beta.36
```
预期输出如下所示：
>``` plain
>NAME                 CHART VERSION  APP VERSION  DESCRIPTION
>blueking/bk-monitor  3.9.0-beta.36  略             略
>```

接下来开始升级了。

先进入工作目录：
``` bash
cd $INSTALL_DIR/blueking/  # 进入工作目录
```

修改 `environments/default/version.yaml` 文件，配置 bk-monitor charts version 为 `3.9.0-beta.36`：
``` bash
sed -i 's/bk-monitor:.*/bk-monitor: "3.9.0-beta.36"/' environments/default/version.yaml
grep bk-monitor environments/default/version.yaml  # 检查修改结果
```
预期输出：
>``` yaml
>  bk-monitor: "3.9.0-beta.36"
>```

更新 bk-monitor：
``` bash
helmfile -f 04-bkmonitor.yaml.gotmpl -l name=bk-monitor sync
```

等待命令执行完毕，结尾输出如下即为更新成功：
>``` plain
>UPDATED RELEASES:
>NAME        CHART                VERSION
>bk-monitor  blueking/bk-monitor  3.9.0-beta.36
>```
