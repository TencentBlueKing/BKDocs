# MCP管理

【智能体开发】-》【MCP】tab下可以查看 “全部/我创建的/已归档的 MCP”。

![MCP_Management_20260820175855.png](../assets/MCP_Management_20260820175855.png)

支持快捷安装至本地IDE。

![MCP_Management_20260820175920.png](../assets/MCP_Management_20260820175920.png)

注册/编辑 MCP，需要填写MCP的基本信息，链接和凭证。

- 支持使用在AIDEV平台已定义的凭证：

![MCP_Management_20260820180028.png](../assets/MCP_Management_20260820180028.png)

- 如需使用蓝鲸应用认证，请前往 "API 网关" 创建 MCP，即可无需注册，在智能体直接绑定：

![MCP_Management_20260820180002.png](../assets/MCP_Management_20260820180002.png)

可以在MCP详情页查看拉取到的MCP的工具列表、请求参数、服务配置。

![MCP_Management_20260820180116.png](../assets/MCP_Management_20260820180116.png)
