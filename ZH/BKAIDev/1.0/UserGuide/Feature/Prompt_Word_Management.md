# 提示词管理

【智能体开发】-》【Prompt】tab下可以查看 “全部/我创建的/已归档的 Prompt”，所有 Prompt 均可以快捷发起会话。

![Prompt_Word_Management_20260814173034.png](../assets/Prompt_Word_Management_20260814173034.png)

创建/编辑 Prompt，支持以 {{ Var }} 的形式使用变量。

可以在 Prompt 编辑页右侧查看当前 Prompt 的测试结果，以便即时修改 Prompt。

![Prompt_Word_Management_20260820174405.png](../assets/Prompt_Word_Management_20260820174303.png)

Prompt 提交后，即可在会话中使用。

![2026-03-11-16-19-08.png](../assets/2026-03-11-16-19-08.png)
