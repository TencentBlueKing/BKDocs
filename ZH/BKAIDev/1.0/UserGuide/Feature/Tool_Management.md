# 工具管理

【智能体开发】-》【工具】tab下可以查看 “全部/我创建的/已归档的 工具”，并可以进行调试。

![Tool_Management_20260820180814.png](../assets/Tool_Management_20260820180814.png)

![Tool_Management_20260820180833.png](../assets/Tool_Management_20260820180833.png)

创建/编辑 工具，需要填写工具的基本信息、凭证、调用接口（支持变量）和请求参数。

![Tool_Management_20260820180937.png](../assets/Tool_Management_20260820180937.png)

![Tool_Management_20260820180953.png](../assets/Tool_Management_20260820180953.png)

支持下列凭证：

- 蓝鲸应用认证：智能体在绑定此工具时需要获取此工具的接口权限，并提供智能体的bk_app_code、bk_app_secret作为认证信息使用该工具。

- 使用自己在凭证管理中添加的凭证。
