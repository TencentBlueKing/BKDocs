### Versioning Scheme

Release package versions follow the format `v{major}.{minor}.{patch}-{phase}.{serial}[-{mark}]`:

| Field | Description | Example |
| --- | --- | --- |
| `major` | Major version | `3` |
| `minor` | Minor version | `0` |
| `patch` | Patch version | `1` |
| `phase` | Release phase | `alpha`, `beta`, `release` |
| `serial` | Iteration number within the current phase | `1` |
| `mark` | Optional marker for test, channel, or temporary identifiers | `test` |

Examples: `v3.0.1-beta.1`, `v3.0.1-beta.1-test`.

> Note: Node Manager V3 is under active development. Please refer to the GitHub Releases page for the latest published versions.
