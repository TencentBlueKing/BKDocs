# Open Source Contribution Guide

BlueKing Node Manager (bk-nodemgr) is open source on GitHub. Contributions via Issues or Pull Requests are welcome.

- Repository: [https://github.com/TencentBlueKing/bk-nodemgr](https://github.com/TencentBlueKing/bk-nodemgr)
- License: [MIT](https://github.com/TencentBlueKing/bk-nodemgr/blob/master/LICENSE.txt)

## Guidelines

1. **Issues**: When filing an issue, please follow the repository's issue templates (bug_report / feature_request / discussion) and provide version numbers, reproduction steps, logs, and other relevant information.
2. **Pull Requests**: Before submitting a PR, read the [Contributing Guide](https://github.com/TencentBlueKing/bk-nodemgr/blob/master/.github/CONTRIBUTING.md) to learn about branch management, issue and PR conventions, and fill in the PR template.
3. **Code of Conduct**: Please follow the [Code of Conduct](https://github.com/TencentBlueKing/bk-nodemgr/blob/master/.github/CODE_OF_CONDUCT.md) when participating in the community.
4. **Versioning**: Node Manager V3 follows the versioning scheme `v{major}.{minor}.{patch}-{phase}.{serial}[-{mark}]` (e.g. `v3.0.1-beta.1`). Git tags match the released package versions.
