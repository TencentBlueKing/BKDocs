# BlueKing Node Manager

BlueKing Node Manager (bk-nodemgr) is the host node management service of the BlueKing ecosystem. It provides full lifecycle control for GSE Agents on managed nodes — install, upgrade, reconfig, restart, uninstall — and supports cross-network Proxy bridging, configuration policies, plugin management, and package management.

- Source repository: [TencentBlueKing/bk-nodemgr](https://github.com/TencentBlueKing/bk-nodemgr)
